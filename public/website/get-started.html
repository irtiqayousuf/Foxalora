Get started

Up and running in an afternoon.

Install Foxalora on your server, then let the setup wizard guide you through the rest. No coding needed.

Install nowTry the setup wizard
Step 1

Install with Docker.

You'll need a Linux server with Docker, and Nginx for HTTPS.

What you need

  • A Linux server (any modern distribution)
  • Docker and Docker Compose
  • A domain such as webmail.yourhost.com
  • An HTTPS certificate (e.g. Let's Encrypt)
  • Your IMAP and SMTP server addresses
# 1. Download Foxalora
git clone https://github.com/foxalora/foxalora.git
cd foxalora

# 2. Start it
docker compose up -d

# 3. Open the setup wizard
#    https://webmail.yourhost.com/setup

The setup page locks itself once setup is complete, so nobody else can use it.
